# MCP-сервер Grow Money

MCP (Model Context Protocol) — стандартный способ дать Claude доступ к данным. Этот сервер — небольшая программа на вашем Mac:
Claude сам запускает её, когда вы спрашиваете о своих финансах, получает нужные цифры и отвечает. Сервер **только читает** —
изменить что-либо в аккаунте или в файлах он не может.

## Что можно спросить

- «Сколько я потратил на еду в сентябре? А в среднем за месяц?»
- «Как менялись расходы на такси за последний год — по месяцам»
- «Какой у меня сейчас капитал и в каких валютах? Как он вырос за полгода?»
- «Во сколько обошлась поездка в Гонконг и на что ушло больше всего?»
- «Какие подписки и регулярные платежи я плачу и сколько это в месяц?»
- «Сколько я теряю на обмене валют и где менять выгоднее?»
- «Когда я накоплю на цель при нынешнем темпе?»
- «Сравни траты до и после переезда в Бангкок»

В Claude Desktop есть два готовых сценария: «＋» → **Add from grow-money** → *Full financial review* (полный разбор,
как на странице AI Export) или *Review a month* (разбор месяца).

## Откуда берутся данные

| Что | Откуда |
|---|---|
| Операции (расходы, доходы, переводы) | самый свежий бэкап (`.mmbackup`) или Excel-выгрузка приложения учёта в папке «Загрузки» — тот же файл, что вы импортируете в Grow Money |
| Кошельки, поездки, цели, лимиты, вехи, зарплата | ваш аккаунт Grow Money (нужно один раз войти, см. ниже) |
| Курсы валют | тот же источник, что в приложении (currency-api); дневные курсы сохраняются в `~/.grow-money/rates` |

Сервер считает **тем же кодом, что и приложение** (`src/lib`), поэтому цифры совпадают со страницами.
Чтобы ответы были свежими, сделайте новый бэкап в приложении учёта и сохраните его в «Загрузки» — сервер сам возьмёт
самый новый файл (импортировать его в Grow Money для этого не обязательно).

Без входа в аккаунт сервер тоже работает: балансы кошельков возьмёт из бэкапа, а поездок, целей и лимитов не будет.

## Подключение

1. **Войти один раз** (из любой папки):
   ```bash
   node /Users/roma/Developer/grow-money/mcp/run.mjs login
   ```
   Введите email и пароль Grow Money. Пароль отправляется в Supabase один раз и нигде не сохраняется; сервер хранит только
   токен сессии в `~/.grow-money/session.json` (доступен только вашему пользователю macOS) и сам его продлевает.

2. **Claude Desktop** — в `~/Library/Application Support/Claude/claude_desktop_config.json`, раздел `mcpServers`:
   ```json
   "grow-money": {
     "command": "/usr/local/bin/node",
     "args": ["/Users/roma/Developer/grow-money/mcp/run.mjs"]
   }
   ```
   Затем полностью перезапустить Claude Desktop (⌘Q и открыть снова).

3. **Claude Code**:
   ```bash
   claude mcp add --scope user grow-money -- /usr/local/bin/node /Users/roma/Developer/grow-money/mcp/run.mjs
   ```

4. **Проверить**, что сервер видит:
   ```bash
   node /Users/roma/Developer/grow-money/mcp/run.mjs status
   ```

## Безопасность

- Только чтение: к аккаунту сервер делает лишь запросы на чтение, а на диск пишет только свой кэш курсов и файл сессии.
- Работает на вашем Mac. В сеть ходит только в ваш аккаунт Supabase и за курсами валют.
- То, что Claude запросил, уходит в Claude — так же, как если вставить AI Export в чат.
- Выйти: `node /Users/roma/Developer/grow-money/mcp/run.mjs logout` — сессия закрывается на сервере Supabase, токен удаляется.

## Инструменты

| Инструмент | Что даёт |
|---|---|
| `get_overview` | общая картина: свежесть данных, капитал по валютам, текущий месяц с прогнозом, прошлый месяц, средние, регулярные платежи, поездки, ближайшая цель |
| `list_categories` | точные названия категорий, кошельков, тегов, валют и поездок |
| `query_transactions` | поиск и подсчёт операций: фильтры по датам, категориям, кошелькам, тегам, тексту, сумме, поездке; группировка по месяцам, категориям, магазинам и т. п. |
| `get_analytics` | готовые отчёты приложения (AI Analyst Export) по разделам: расходы, магазины, регулярные платежи, бюджет, доходы, обмен валют, кошельки, поездки, вехи, качество учёта |
| `get_wallets` | кошельки и капитал, по желанию — капитал по неделям или месяцам |
| `get_trips` | все поездки или разбор одной: по категориям и дням, против жизни дома, возможно пропущенные платежи |
| `get_goals` | цели: сколько накоплено и когда будут достигнуты при нынешнем темпе |

Любой инструмент можно вызвать из терминала:
`node mcp/run.mjs call query_transactions '{"month":"2026-09","group_by":["category"]}'`.

## Настройки (необязательно)

Переменные окружения в блоке `env` конфига MCP:

- `GROW_MONEY_STATEMENT_DIR` — где искать бэкап, если не в «Загрузках» (несколько папок — через `:`);
- `GROW_MONEY_STATEMENT` — один конкретный файл;
- `GROW_MONEY_HOME` — где хранить сессию и кэш (по умолчанию `~/.grow-money`).

## Если что-то не так

- **«No backup … in ~/Downloads»** — сделайте бэкап в приложении учёта и сохраните его в «Загрузки».
- **«macOS didn't let the server read ~/Downloads»** — Системные настройки → Конфиденциальность и безопасность →
  Файлы и папки → разрешите Claude доступ к папке «Загрузки».
- **«sign-in has expired»** — снова выполните `login`.
- **Цифры отличаются от приложения** — сервер берёт самый новый файл из «Загрузок», а приложение показывает последний
  импортированный. `status` покажет, какой файл используется.

## Для разработки

Код — в `mcp/`: `server.ts` (MCP), `tools/` (инструменты), `context.ts` (сборка данных), `statement.ts` (файл выписки),
`appData.ts` + `session.ts` (аккаунт), `rates.ts` (курсы). Сервер запускается через tsx прямо из исходников, без сборки,
поэтому всегда работает на текущем коде `src/lib`. Типы проверяются вместе с приложением (`tsconfig.mcp.json` входит в
`npm run build`).
